# Roadmap de Características - Notion Clone

## 🎯 Visión General

Transformar Notion Clone de un MVP básico a una aplicación de productividad completa con características avanzadas.

## 📅 Fase 1: MVP (Completado ✅)

### Core Features
- [x] Crear, editar, eliminar páginas
- [x] Editor de texto enriquecido
- [x] Almacenamiento local (SQLite)
- [x] Auto-guardado automático
- [x] UI limpia y responsiva

---

## 📅 Fase 2: Expansión (Próximo Sprint)

### 2.1 Jerarquía de Páginas
- [ ] Crear sub-páginas dentro de otras
- [ ] Navegar entre niveles
- [ ] Mostrar "breadcrumb" en el editor
- [ ] Eliminar páginas con sus hijos

**Estimado**: 1-2 semanas

### 2.2 Búsqueda y Filtrado
- [ ] Buscador global en tiempo real
- [ ] Búsqueda por título
- [ ] Búsqueda en contenido
- [ ] Historial de búsquedas recientes

**Estimado**: 1 semana

### 2.3 Exportación
- [ ] Exportar a PDF
