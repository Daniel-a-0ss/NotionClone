## 🚀 CÓMO USAR

### Crear una Nueva Página

1. **Haz clic en "+ Nueva página"**
   ```
   Aparecerá un formulario para crear página
   ```

2. **Ingresa el nombre de la página**
   ```
   Ejemplo: "Mi proyecto importante"
   ```

3. **Selecciona una plantilla**
   ```
   Elige el emoji y tipo de página que deseas
   ```

4. **¡Listo! Tu página está creada**
   ```
   Ahora puedes escribir en ella
   ```

### Editar Contenido

1. **Selecciona una página del sidebar**
   ```
   Haz clic en el nombre de la página
   ```

2. **Escribe en el editor**
   ```
   El editor es como Word/Notion
   ```

3. **Usa el toolbar para dar formato**
   - **B** - Negrita
   - **I** - Cursiva
   - **H1** - Título grande
   - **H2** - Título mediano
   - **•** - Lista con viñetas
   - **1.** - Lista numerada

4. **Los cambios se guardan automáticamente**
   ```
   No necesitas presionar nada
   ```

### Eliminar una Página

1. **Pasa el cursor sobre la página**
2. **Haz clic en la X roja**
3. **Confirma la eliminación**

## 🔧 TÉCNICA

### Stack
- React 18 + TypeScript
- TipTap (Editor WYSIWYG)
- Electron (Desktop app)
- Zustand (State management)
- JSON DB (Base de datos)

### Comandos Útiles

**Desarrollo**
```bash
npm run dev          # Ejecutar en desarrollo
```

**Compilar**
```bash
npm run build        # Generar instalador
```

**Limpiar**
```bash
npm cache clean --force
rm -r node_modules dist
npm install
```
